2. USER DECISION APPLIED: GIF EXCLUDED
--------------------------------------
- webp/class-ctgen-webp-converter.php: ALLOWED_SOURCE_MIME_TYPES is now
  JPEG + PNG. Any GIF (static or animated) is rejected before an editor
  loads it, with its own code: ctgen_webp_gif_excluded.
- The animated-GIF detection code (Imagick frame count + byte scan) was
  removed as dead code.
- webp/class-ctgen-webp-ajax-handlers.php: GIF attachments are no longer
  returned as eligible; the convert endpoint refuses a GIF attachment as a
  whole (ctgen_webp_gif_excluded) and any other non-JPEG/PNG image
  (ctgen_webp_unsupported_attachment_type).
- templates/ctgen-form-html.php: info notice on the settings page, below the
  regeneration controls:
  "WebP conversion: Animated GIFs are not convertible to WebP without losing
   their animation, so GIF images are not converted. JPEG and PNG thumbnails
   are converted."
- Backups: webp/class-ctgen-webp-converter.php.bak,
  webp/class-ctgen-webp-ajax-handlers.php.bak (both = git HEAD).
